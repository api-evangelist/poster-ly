Posterly is a SaaS platform that provides social media scheduling and publishing across 18 platforms. It offers AI‑assisted content creation, bulk upload, client approvals, and brand visual adapters. Designed for agencies, creators, and businesses, Posterly centralizes content planning, scheduling, and analytics, helping users save hours each month while maintaining brand consistency.

**Areas:** Social Media · SaaS · Scheduling · AI · Marketing

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Posterly: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
